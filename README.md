# Portfolio de Hanaa Traoré

Site portfolio réalisé avec Next.js 16, React 19, TypeScript et Tailwind CSS 4.

```bash
npm install     # installer les dépendances (une seule fois)
npm run dev     # lancer le site en local sur http://localhost:3000
npm run build   # vérifier que le site compile pour la production
```

Tout le contenu (profil, expériences, formation, compétences, projets) se modifie dans `src/data/`.
Le guide complet d’installation, de personnalisation et de mise en ligne est dans **GUIDE.md**.
